* 개발 방식
 - 향후 Database 연동을 위하여 단순히 html 형태로 개발되면 안됨.
 - Vercel에 Deploy 하기 위하여 FrontEnd, BackEnd로 분리해서 개발되어야 함.
 - FrontEnd, BackEnd 기술은 Vercel에 Deploy 되어야 하므로 그에 맞는 기술 스택을 사용해여 함.
 - 원 페이지 형식으로 개발.
 - 개발 소스는 Java 관련된 내용은 지양.
